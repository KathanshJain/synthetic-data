# Machine Learning on Artificially Forged Data

A mini-project (CSET312) by **Aryan Gupta** and **Kathansh Jain**, Bennett University.

## Project Overview (the short story)

Imagine an organisation that holds a table of personal records. It cannot share the full
table, so a team receives only a small sample. Can that team learn the patterns in the
small sample, generate extra *artificial* records, and train a model on the artificial
records that still works on real, unseen data? That is exactly what we measure. We ask:
**how much real data does a generator need?** — and we answer with a controlled
experiment, not a guess.

## Research Question

How does the size of a small real "seed" sample affect the **fidelity**, downstream
**utility**, and **privacy risk** of synthetic tabular data generated by CTGAN and
Gaussian Copula, using the Adult Census Income dataset?

## Folder Structure

```
synthetic-data-project/
  config.yaml            all settings (no hard-coded numbers in code)
  criteria.yaml          pass/fail rules for the minimum useful seed
  requirements.txt       libraries
  PROJECT_BRIEF.md       the full brief
  data/raw/              downloaded raw Adult data
  data/processed/        cleaned dev pool
  data/locked/           locked test set + manifest.json (hash)
  data/seeds/            nested stratified seeds per random seed
  data/synthetic/        generated synthetic CSVs
  src/                   all pipeline code
  app/                   Streamlit app
  tests/                 pytest tests (split, seeds, fidelity, leakage)
  results/               metrics.csv, fidelity.csv, privacy.csv, RESULTS.md
  figures/               all plots
  reports/               eda_report.md
```

## How to Run Each Step

| Step | Command | Produces |
|------|---------|----------|
| 1. Data prep | `python -m src.prepare_data` | data/processed/dev_pool.csv, data/locked/* |
| 2. EDA | `python -m src.eda` | figures/eda/, reports/eda_report.md |
| 3. Seeds | `python -m src.seeds` | data/seeds/rs{0,1,2}/seed_*.csv |
| 4. Generators demo | `python -m src.generators` | demo output + figures |
| 5. Fidelity demo | `python -m src.fidelity` | demo metrics + example plots |
| 6. Privacy demo | `python -m src.privacy` | DCR demo output + plot |
| 7. Models demo | `python -m src.models` | validation metrics (no locked test!) |
| 8. Quick experiment | `python -m src.run_experiment --quick` | results/quick/* |
| 8b. Full experiment | `python -m src.run_experiment` | results/*.csv (ONLY after approval) |
| 9. Analysis | `python -m src.analyze` | figures/results/, results/RESULTS.md |
| 10. App | `streamlit run app/streamlit_app.py` | local web app |
| Tests | `python -m pytest` | test report |

## Limitations

privacy guarantee), no time-series support.
